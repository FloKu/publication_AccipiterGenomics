The repository contains the codes and input files for the phylogenetic analyses, described and published in the paper

"Goshawk genomics: Genome wide Single Nucleotide Polymorphisms (SNPs) confirm Species Status of Astur gentilis and Astur atricapillus"

The repository contains: 
+) the final files used in phylogegentic analyses
  * FINAL_63inds.vcf: This is the final data file in VCF format, AFTER the stackspipeline BEFORE individuals were removed based on percentage of missing data
  * FINAL_63inds.nexus: This is the same data as FINAL_63inds.vcf but in NEXUS format.
  * FINAL_52inds_manuel.nexus: This is the final data file used in the phylogenetic analyses, AFTER individuals were removed based on missing percentage. 
	It includes 52 individuals genotyped at 40,116 SNP loci (of which 39,903 were polymorph).
  * FINAL_52inds_manuel.nexus.varsites.phy: This is the final file that was generated by IQTree during the the ML tree calculation. 
	Although we startet the analysis with FINAL_52inds_manuel.nexus, IQTree cannot handle invariant sites (presumably including sites with missing data), and hence automatically subsets and creates a variant-sites-only file in PHYLLIP format.
+) the scripts and shell codes used to run the whole pipeline
